## 用途与模型角色

增强XGBoost x3提供主风险信号；GraphSAGE保留实验分数、历史关系和负实验报告，不参与主评分或融合。Agent组合交易、历史、模型、关系和模拟政策，报告仍须人工复核；没有自动冻结账户、阻断交易等外部动作。分数未作业务概率校准，0.9不能解释为已证实90%欺诈概率。

## 实现与训练

| 项目 | 固定内容 |
|---|---|
| XGBoost | x3，max_depth6、learning_rate0.025、min_child_weight5，最多2000轮，内层AP早停；每折独立训练期预处理 |
| 图模型 | 两层同构mean GraphSAGE，191维（28根输入+163 core编码），hidden64、dropout0.4、lr0.001；32,833参数 |
| 图上下文 | 每实体最近5笔严格历史，当前/同秒/未来事件不作历史；根额外core编码，其他节点附加维为0 |
| 确认 | 三折、GNN每折三种子20260921/20260928/20261007，共9图+3树真实fit |
| 图训练上限 | batch256、最多25 epoch、patience10、训练负正比权重；有运行最佳轮次触及25轮上限 |
| 融合 | 每折校准段比较预先固定alpha网格，三个种子校准AP均值选一个alpha，并列偏更高XGB；三折均alpha=1 |

不能宣称GraphSAGE已经达到理论最优或充分穷尽调参。宽表XGB与图模型的信息输入不同，业务差距不能全部归于图结构。路线4匹配core有图/无边内层AP为0.391845/0.374341，是单折关系探索证据，未转化为路线5正式融合增量。

## 评估口径与结果

一份IEEE-CIS标注交易表590,540行；development为原train+validation共501,959。三个滚动训练窗口重叠，三个外层窗口不重叠，每折50,196、合计150,588；九种子结果不等于九份独立数据。

| 冻结评估 | AP | ROC-AUC | 用途 |
|---|---:|---:|---|
| 第一折早停x3 | 0.726914 | 0.934365 | 开发/选型，不能当测试成绩 |
| 三折外层XGB均值 | 0.544367 | 0.905089 | 固定方案确认；最差折ROC0.887805 |
| 固定融合 | 与XGB相同 | 与XGB相同 | alpha全1，AP增量0，正收益0/3 |
| 历史test的fold3 XGB | 0.537789 | 0.903670 | 88,581笔描述性复核，历史已观察，不是新盲测 |

AP采用average_precision_score，不是准确率或梯形积分AUPRC。正式门槛为基础ROC≥0.80；图晋级另需AP绝对+0.005、Top1%召回相对+5%、至少两折正增量及稳定性。本次基础通过，图增量失败；配对日块bootstrap的两项增量95%区间均[0,0]，不晋级。不能写成“所有GNN都无效”。

预处理/词表/编码器只fit本折train；模型/融合规则先冻结再统一查看外层。历史test最多一个已记账描述性批次；不存在可宣传的新独立盲测。原始匿名字段的可用时点限制见[数据卡](stage-09-5b-data-card.md)。

## 服务覆盖与资源

原validation 88,581笔使用早于整段的fold2，test 88,581笔用fold3；合计177,162笔均有时点图索引和合格分数。此覆盖率不是准确率。训练期历史邻居没有新增时间OOF分数，显示relation_only/null；跨折图分数不混为同一风险排序。

新事件使用冻结模型和严格历史，标记prospective_replay，不写历史、也不表示质量已验证。原训练资源最低可用3GiB不改；路线6独立CPU推理合同为最低可用1.5GiB、单进程1280MiB。UBJ树独立进程、图批次64、数据分块；一次性格式转换另计预算。各进程峰值不能直接当整机同时峰值。

## 不适用与限制

- 未经过真实企业分布、人工复核实用性、业务阈值/成本和概率校准验收；
- 匿名字段时点假设不等于真实上线可用，identity_key不是身份认证；
- GraphSAGE没有稳定融合收益，异构模型Deferred，既有失败不删除、不退预算；

- 容器/数据库/确定性报告夹具通过只证明工程行为，不增加真实LLM质量分母；
- 演示复核员身份未认证、单worker语义、持续追加索引/正式负载/生产备份仍是交付边界。
