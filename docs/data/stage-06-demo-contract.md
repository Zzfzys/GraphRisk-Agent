## 展示与数据边界

工作台只请求 FastAPI；FastAPI 才加载 Stage 05 运行器、模型、图和检索器。外发给浏览器的调查视图采用明确字段白名单：交易 ID、必要的交易事实和证据 ID、模型版本与**未校准**分数、图状态及历史邻居/路径、政策标题/版本/章节/适用日期/原文出处、报告状态和不确定性、审计摘要与审批状态。图邻居为空与图产物失败必须分开显示；分数不写成已证实欺诈或校准概率。模拟政策须醒目标记，`source_quote_verified` 仅说明引文来源匹配，不说明该政策已自动适用于交易。

禁止返回或显示测试标签、整份原始 CSV/Parquet、直接身份标识、环境变量、密钥、完整模型输入提示或生成原文。`identity_key` 是启发式关联键，不写成已验证客户 ID。报告如含交易金额，仅展示单笔必要事实，不开放原始明细下载。日志记录 `run_id`、状态、耗时、版本和错误码；不记录原始交易行、政策全文或模型请求/响应。生成报告与审批快照留在 Git 忽略的本地产物目录；版本化文档只记哈希、命令和不敏感摘要。

## 进程与权限边界

- 本地入口预留 API `127.0.0.1:8000`、Streamlit `127.0.0.1:8501`、宿主 Ollama `127.0.0.1:11434`。运行前检查端口可用；不开放局域网监听。
- FastAPI 单进程、单 worker 拥有共享费用账本、有界运行记录、报告与 `InMemorySaver` 审批检查点。Streamlit `session_state` 只存界面状态和查询用 `run_id`。页面重跑/刷新先查已有运行，不隐式再次调用模型；API 重启后旧待审会话明确失效。
- 审批必须绑定会话、交易、冻结报告 SHA-256 和有效期。演示 `reviewer_id` 只是输入字段，不构成认证；批准和拒绝都只更新建议/审计，不触发封禁、拒付、通知或支付动作。正式认证和跨进程恢复属后续阶段。
- 容器演示须实际运行才能验收。路线 5 已新增独立 `host_ollama` 配置，只允许 `http://host.docker.internal:11434/api/generate` 并继续核对模型 digest；原有 `local_http` 仍只允许回环，不能接受任意远程 HTTP。容器内的 `127.0.0.1` 指向容器自身。Dockerfile 与 Compose 已将原始数据、模型权重和密钥排除镜像，数据/工件以只读卷提供，报告目录单独可写；2026-09-27 容器 API/工作台均通过健康检查，真实调查与拒绝成功；镜像文件扫描、挂载检查及 Compose 关闭均通过，证据见[路线 5 验收记录](../../reports/stage-06-route-5-local-compose.md)。

本契约的成功标准是能解释每个输出来自哪项证据，并能展示审批和失败分支的真实状态。它不声称真实企业政策、生产身份认证、跨进程持久性或自动处置。
