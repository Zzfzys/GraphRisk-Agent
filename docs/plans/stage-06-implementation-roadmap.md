## 目标与范围

在一台本地机器上，让面试演示者输入 IEEE-CIS held-out 交易和显式 `policy_as_of`，通过 FastAPI 取得 Stage 05 的受控调查报告，在 Streamlit 中看到模型、图和政策三类证据，完成有哈希绑定的人工批准/拒绝与备注；一条命令可启动本地演示，Docker Compose 可在具备 Docker 的环境中验证。首批 17 个固定 Agent 案例扩至至少 50 个，生成可重跑的评估与限制报告。Stage 06 是单机演示 MVP，不声称生产认证、跨进程审批恢复、真实企业政策或自动处置。

```text
Streamlit（只负责展示与用户输入）
    ↓ HTTP
FastAPI（唯一业务入口；单进程持有运行记录和审批检查点）
    ↓
Stage05ReliableRunner → Stage04 五工具 + 版本化政策检索 + 本地生成
    ↓
来源约束报告 → 人工审批 pending / approved / rejected
```

已经存在的 `api/main.py` 仅提供 Stage 02 `/risk/predict`；Stage 06 在其上扩展，不另起一套风控逻辑。路线 0 已将 Streamlit 1.64.0 纳入仓库 `demo` 依赖组，并复跑 Stage 05 交接；[门禁记录](../../reports/stage-06-route-0-preflight.md)和[演示契约](../data/stage-06-demo-contract.md)已冻结。2026-09-27 已安装 Docker CLI/Compose，最终恢复 Engine 并通过路线 5 容器门禁。Stage 05 的 `Stage05ApprovalWorkflow` 使用 `InMemorySaver`：API 必须在**同一进程**保存报告与检查点，演示只允许单 worker；刷新页面不得重跑调查，服务重启后的旧审批必须明确失效。Stage 07 才做跨进程持久检查点与正式认证。
