- 归纳学习与图泄漏；
- 图模型与表格模型的公平比较。

## 风险与降级方案

- 全量图内存不足：从 50k/100k 交易里程碑开始，使用邻居采样；
- GNN 指标不优于 XGBoost：如实报告图模型的价值和限制；
- Neo4j 未就绪：使用本地图结构实现查询接口，Neo4j 后置。

## 决策记录

| 日期 | 决定 | 原因 | 影响 |
|---|---|---|---|
| 2026-09-21 | 只要求一个 GraphSAGE 基线 | 求职主线转向 Agent，控制 GNN 投入 | 异构 GNN 作为增强项 |
| 2026-09-23 | 使用按目标交易截止时间构建的严格历史 ego graph | 整个训练期静态图会让早期交易看到后来的结构 | 训练、验证、测试都必须执行逐目标时间过滤 |
| 2026-09-23 | 首版保留交易—实体直接图，不投影成交易 clique | 高频实体投影可能造成边数平方增长且丢失路径语义 | 使用 Transaction、Card、Device、EmailDomain、Address 五类节点 |
| 2026-09-23 | XGBoost、GraphSAGE 与融合只在相同交易 ID 上比较 | 保证指标公平且可审计 | 保存评估 ID 集合与哈希，缺失或重复直接失败 |
| 2026-09-23 | 风险邻居只使用严格历史关系和模型分数，不暴露标签 | 模型证据不是已确认欺诈事实 | 工具输出保留分数未校准和实体启发式限制 |
| 2026-09-23 | 受控主对比让 XGBoost 与 GraphSAGE 使用同一训练 ID | 同测试 ID 但训练预算不同仍会影响解释 | Stage 02 全量 champion 仅作为单独参考行 |
| 2026-09-23 | PyTorch 使用官方 CUDA 12.8 索引，PyG 使用 PyPI 已发布版本；CPU 始终可运行 | 本机有 RTX 2060，但正确性不能依赖 GPU 可用 | 锁定依赖并执行双设备 smoke |
| 2026-09-23 | 用逐目标小图作为时间语义参考实现；每根实体的历史交易按时间倒序、ID 正序截断 | 静态全图与不稳定采样会污染早期目标或破坏复现 | 路线 2 大规模索引必须与参考 fixture 结果一致 |
| 2026-09-23 | `fanout: [10, 5]` 保留四类根实体，每实体最多选五笔较早交易 | 首版根实体最多四类，避免无意义地舍弃一类证据 | 训练、评估和查询复用同一 manifest 中的采样规则 |
| 2026-09-23 | GraphSAGE 仅按验证 PR-AUC 选 checkpoint；测试标签来源检查也延后到权重冻结后 | 保持测试集不参与训练和选模 | 第 2 轮权重在第 6 轮早停后恢复，再完成一次测试评估 |
| 2026-09-23 | 自助调参采用独立运行名和只验证模式 | 防止试参覆盖基线或提前读取测试标签 | 仅用验证 PR-AUC 比较候选，选定后再运行一次完整测试 |
| 2026-09-23 | 融合固定五个候选 alpha，仅按验证 PR-AUC 选择 | 避免测试集参与模型组合选择 | alpha=0.5；测试 PR-AUC 未超过受控 XGBoost，如实保留 |
| 2026-09-23 | 风险邻居只用经校验的验证/测试分数，目标也须有 held-out 分数 | 训练 in-sample 分数不能冒充独立风险证据 | 训练和未覆盖目标返回 `graph_prediction_unavailable`；空邻居返回 `ok` |
