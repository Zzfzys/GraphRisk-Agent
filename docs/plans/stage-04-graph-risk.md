# Stage 04：GraphSAGE 与图查询工具

> 状态：Planned  
> 计划时间：Week 5  
> 前置阶段：Stage 01、Stage 02、Stage 03

## 阶段目标

验证关系图能否为欺诈识别提供额外信息，并把图模型与图查询能力暴露为 Agent 工具。

## 学习任务

- 图 schema、节点和边的时间边界；
- GraphSAGE、邻居采样和 mini-batch；
- 归纳学习与图泄漏；
- 图模型与表格模型的公平比较。

## 实现任务

- [ ] 构建 Transaction、Card、Device、EmailDomain 和 Address 实体；
- [ ] 建立 PyG 图数据；
- [ ] 保证训练图不包含未来关系；
- [ ] 训练受控规模 GraphSAGE；
- [ ] 输出图风险分数和 embedding；
- [ ] 与 XGBoost 使用同一测试集比较；
- [ ] 实现简单分数融合；
- [ ] 完成相关实体和风险邻居查询工具。

## 交付物

- 图 schema 文档；
- GraphSAGE 训练与评估报告；
- XGBoost、GraphSAGE 与融合对比表；
- 图查询工具及测试。

## 验收标准

- [ ] 图构建规则可复现；
- [ ] 图数据具有时间泄漏测试；
- [ ] 训练可在当前 6GB 显存设备或 CPU 模式完成；
- [ ] 模型对比使用相同测试交易；
- [ ] Agent 工具可以返回具名实体与关系证据。

## 风险与降级方案

- 全量图内存不足：从 50k/100k 交易里程碑开始，使用邻居采样；
- GNN 指标不优于 XGBoost：如实报告图模型的价值和限制；
- Neo4j 未就绪：使用本地图结构实现查询接口，Neo4j 后置。
