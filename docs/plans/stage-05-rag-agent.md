建立带来源引用的风控政策检索，并将调查工具编排成可恢复、可审批的 LangGraph 工作流。

- Retrieval evaluation；
- LangGraph state、node、edge、checkpoint；
- Structured output、工具调用和人工审批；
- Prompt injection 与证据约束基础。

## 验收标准

- [ ] 每条政策结论都可追溯至文档片段；
- [ ] 无证据时系统明确表达信息不足；
- [ ] Agent 不会绕过人工审批执行高风险动作；
- [ ] 工具失败后能够重试、降级或终止；
- [ ] 评估集能够重复运行并记录模型、Token、费用和延迟。

路线 0 的[门禁记录](../../reports/stage-05-route-0-preflight.md)：Stage 04 正式调查五工具 `ok`；LangGraph 1.2.12 fake 图与 Ollama `qwen2.5:0.5b` 真实 JSON smoke 通过；聚焦 22 项、全量 188 项测试通过，离线锁文件核对成功。字段边界见[实验契约](../data/stage-05-experiment-contract.md)。这不构成政策 RAG、正式 Agent 报告或审批的 Stage 05 总验收。

## 风险与降级方案

- pgvector 尚不可用：使用接口兼容的本地检索实现；
- API 输出不稳定：缩小自由度并强化 schema 验证；
- 调用成本上升：缓存中间结果并使用小规模开发评估集；
- 文档版权或来源不清：删除对应材料，使用可公开资料或自建模拟政策。
- 本地服务离线或模型 digest 改变：路线 0 preflight 明确失败；恢复服务或重新核对模型版本后再运行，不能沿用旧 smoke 证据。
