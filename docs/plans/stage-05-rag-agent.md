## 阶段目标

建立带来源引用的风控政策检索，并将调查工具编排成可恢复、可审批的 LangGraph 工作流。

## 学习任务

- Retrieval evaluation；
- LangGraph state、node、edge、checkpoint；
- Structured output、工具调用和人工审批；
- Prompt injection 与证据约束基础。

路线 6 的[审批契约](../data/stage-05-approval.md)与[验收记录](../../reports/stage-05-route-6-approval.md)：LangGraph `interrupt` 冻结报告哈希、交易和证据摘要；同进程批准/拒绝、错绑、过期、报告变更与幂等重复提交均有测试。9 项聚焦、248 项全量测试通过；真实路线 5 报告的模拟批准/拒绝均无外部处置。复核员身份认证和跨进程持久化尚未交付。

路线 7 的[可靠性与评估契约](../data/stage-05-reliability-evaluation.md)、[17 案例冻结集](../../data/evaluation/stage05_agent_cases_v1.yaml)与[验收记录](../../reports/stage-05-route-7-reliability-evaluation.md)：检索/模型暂时性错误有限重试，配置上限约束真实调用、总时长和费用预留；输入、来源、计划和输出校验错误直接终止。离线 fake 评估 17/17 通过，记录分支、引用、审批零外部动作、延迟与 Token/费用字段。真实本地模型抽样独立报告，不与 fake 成绩混算。

路线 8 的[端到端验收与复盘](../../reports/stage-05-route-8-acceptance.md)：预选交易 `3488959` 仅在 test split；当前图 checkpoint 重新生成 `stage05-route8` 同 ID 比较并经哈希校验，真实五工具调查 `completed`、本地模型派生报告 `verified`、当前政策片段引用逐字/版本/日期/哈希核对通过。同一报告进入 `pending` 后被人工拒绝且无外部动作；无政策拒答与模型断连也由真实 held-out 调查入口复现。冻结检索集 Recall@3 1.000、17/17 Agent 案例、260 项全量测试、包构建和受限文件检查通过。模型不确定性枚举曾与 Stage 04 状态冲突，现只作非权威提示，权威状态和最终不确定性由代码保留；引用/证据/动作仍严格校验。

## 风险与降级方案

- pgvector 尚不可用：使用接口兼容的本地检索实现；
- API 输出不稳定：缩小自由度并强化 schema 验证；
- 调用成本上升：缓存中间结果并使用小规模开发评估集；
- 文档版权或来源不清：删除对应材料，使用可公开资料或自建模拟政策。
- 本地服务离线或模型 digest 改变：路线 0 preflight 明确失败；恢复服务或重新核对模型版本后再运行，不能沿用旧 smoke 证据。

## 计划变更

路线 0 曾因网络与模型未安装而阻塞，现经本地模型续传、摘要核对和 smoke 解除。首次冷启动约 109 秒，生成请求超时从 120 调整至 180 秒。路线 8 将旧图比较产物的哈希错配修复为新版本产物；对真实小模型误报的不确定性改由代码裁决，Stage 05 的引用、审批和失败安全门禁未放松。

## 阶段复盘

Stage 05 最终交付的是可追溯、可拒答、可审批的**受控** Agent 链路：检索/模型选择提供候选，事实、状态、政策原文和审批由代码约束。真实 held-out 演示成功，但语料是 8 份模拟政策、Agent 固定集仅 17 案，不能代表企业大规模制度库或线上质量；GraphSAGE/融合未胜过同 ID 受控 XGBoost，分数也未校准。路线 8 的两次真实失败揭示了产物版本绑定和小模型状态误报的工程风险，现有哈希校验与权威状态边界能够安全暴露并修复。Stage 06 继续交付工作台、API、容器化和 50 案例；跨进程审批持久化与正式费用账本仍属后续阶段。
