# Stage 05：政策 RAG 与受控调查 Agent

> 状态：In Progress（路线 0 部分通过；LangGraph 与真实生成门禁阻塞）
> 计划时间：Week 6～7  
> 实际开始：2026-09-24
> 前置阶段：Stage 03、Stage 04

## 阶段目标

建立带来源引用的风控政策检索，并将调查工具编排成可恢复、可审批的 LangGraph 工作流。

## 学习任务

- 文档切分、embedding、召回和 reranking；
- Retrieval evaluation；
- LangGraph state、node、edge、checkpoint；
- Structured output、工具调用和人工审批；
- Prompt injection 与证据约束基础。

## 实现任务

- [x] 路线 0：冻结同源请求、配置、报告/审计边界和预算，复验 Stage 04 五工具；
- [ ] 路线 0：锁定 LangGraph 并通过 fake 图与真实生成端 smoke；
- [ ] 建立公开资料与模拟企业政策语料；
- [ ] 记录每份文档的来源、版本和属性；
- [ ] 建立 Retriever 接口与 pgvector 实现计划；
- [ ] 构建检索测试集并测量 Recall@K；
- [ ] 实现受控 LangGraph 调查流程；
- [ ] 设置最大步骤数、超时、重试和终止条件；
- [ ] 生成包含证据 ID 和政策引用的结构化报告；
- [ ] 对高风险建议加入人工审批节点；

## 验收标准

- [ ] 每条政策结论都可追溯至文档片段；
- [ ] 无证据时系统明确表达信息不足；
- [ ] Agent 不会绕过人工审批执行高风险动作；
- [ ] 工具失败后能够重试、降级或终止；
- [ ] 评估集能够重复运行并记录模型、Token、费用和延迟。

## 验证证据

路线 0 的[门禁记录](../../reports/stage-05-route-0-preflight.md)：Stage 04 正式调查五工具 `ok`、配置契约 17 项和全量 183 项测试通过、离线锁文件核对成功；真实模型和 LangGraph 未通过，不构成 Stage 05 LLM 验收。字段边界见[实验契约](../data/stage-05-experiment-contract.md)。

## 风险与降级方案

- pgvector 尚不可用：使用接口兼容的本地检索实现；
- API 输出不稳定：缩小自由度并强化 schema 验证；
- 调用成本上升：缓存中间结果并使用小规模开发评估集；
- 文档版权或来源不清：删除对应材料，使用可公开资料或自建模拟政策。
- 本地生成服务/权重和 LangGraph 不可用：保持 provider 未配置，先做独立的语料准备；直到依赖锁、fake 图和真实生成 smoke 有证据，才开展依赖它们的路线。
