## 阶段目标

交付两项能独立讲清的作品能力。第一项是在 GraphRisk-Agent **同一输入与评分合同**下对照本地 Ollama 和一个小额托管 API，解释结构化输出、证据正确性、延迟、资源与费用的取舍。第二项是可独立安装运行的 GraphRAG 企业知识助手：针对**项目原创的模拟 IT 运维知识文档**，联合文本片段和有原文出处的关系边回答一跳、两跳问题，展示引用、路径、版本与拒答。

本阶段服务于 LLM／Agent 应用算法工程师岗位。旧 Stage 06 冻结 50 案和 Stage 07 冻结 15 案是主系统回归门禁，不是模型质量排行榜；原有三个真实样本来自同一交易，不能据此排名模型。[Stage 07 总验收](../../reports/stage-07-route-8-acceptance.md)已记录这些证据范围、数据库恢复和数据边界。

[Ollama 官方文档](https://docs.ollama.com/capabilities/structured-outputs)说明本地结构化输出可使用 JSON Schema；[生成接口](https://docs.ollama.com/api/generate)提供 Token 与耗时字段；[运行模型接口](https://docs.ollama.com/api/ps)可观察模型 digest 和显存占用。实际可用性以本机固定模型实测为准。GraphRAG 只实现带来源的局部图问答；[Microsoft GraphRAG 查询说明](https://microsoft.github.io/graphrag/query/overview/)区分局部图问答与全局社区摘要，本项目不宣称实现其完整框架。

## 不变约束与交付边界

- GraphRisk 的 Stage 06 默认内存路径、Stage 07 显式 PostgreSQL 路径和冻结案例不变。托管 API 只接收原创模拟或合成评估输入，绝不发送原始 IEEE-CIS 行、标签、身份键、数据库凭据或内部调查报告。密钥仅存本地忽略文件／进程环境；路线 0 必须锁定供应商和**小额总预算上限**，否则真实付费调用保持未运行。
- GraphRAG 与欺诈调查、风控政策、Stage 07 运行数据库隔离。约 24 份原创模拟企业 IT 文档应标注文档 ID、版本、生效区间、出处和授权；至少 30 条关系边都必须绑定具体文档片段。模型可提出候选边，但未经来源核验不能进入正式图。
- 独立子项目优先位于 `projects/enterprise-graphrag/`。路线 0 验证它在隔离环境的打包和锁文件方案；运行时不依赖 GraphRisk 业务模块或 IEEE-CIS 工件。只提取稳定的 HTTP／引用通用契约，避免大规模重构已验收主链。
- 图检索限制两跳、固定候选数和时间预算；按文档有效期先过滤，再取文本和关系证据。无答案、错版本、关系缺来源、损坏索引均应安全停止。引用只证明可追溯，不自动证明生成结论正确。

| 部分 | 本阶段必做 | 可延期 |
|---|---|---|
| 模型对照 | fake／本地／托管提供商合同，约 20 个预先冻结的真实 provider 对照案，逐例质量/时间/费用 | 默认服务切换付费模型、自动模型路由 |
| GraphRAG 索引 | 文本基线、本地 embedding、源文关系图、重复构建哈希 | Neo4j、自动无审核抽取、社区摘要 |
| GraphRAG 问答 | 有界结构化答案、片段与关系路径引用、拒答、轻量只读演示 | 工单修改、消息发送、权限操作 |
| 评估 | 至少 30 个冻结问答案，文本/图/混合消融，失败分组 | 只报告平均分或改题制造提升 |

## 风险、删减顺序与决策

- API 凭据或额度未就绪：可并行完成本地和 GraphRAG，但真实 API 对照仍是未完成门禁；不拿 fake 结果充数。
- 显存不足／模型太慢：改用 CPU 或更小量化模型并记录资源和失败，不提高限制掩盖问题。
- 时间超预算：先删 UI 美化、自动关系抽取、图数据库、全局摘要；保留引用、拒答、冻结评估、独立安装与旧主链回归。
- 混合检索没有收益：记录文本基线和逐例差异，检查来源边与查询设计，不改冻结题。
- 原创语料明确标作模拟资料；接入真实企业文档需另行授权与治理。
