# Stage 08：本地模型对比与独立 GraphRAG

> 状态：Planned  
> 计划时间：Week 11～12  
> 前置阶段：Stage 06；建议完成 Stage 07

## 阶段目标

在不影响主系统稳定性的前提下，对比 API 与本地小模型，并复用已有组件形成独立 GraphRAG 企业知识助手。

## 实现任务

- [ ] 建立模型提供商适配接口；
- [ ] 选择可在 6GB 显存或 CPU 上运行的量化小模型；
- [ ] 使用同一 Agent 评估集比较 API 与本地模型；
- [ ] 比较任务完成率、结构化输出、延迟、显存和费用；
- [ ] 提取文档处理、检索、引用和评估组件；
- [ ] 构建独立 GraphRAG 企业知识助手；
- [ ] 为 GraphRAG 建立小型独立评估集和 README。

## 交付物

- API 与本地模型对比报告；
- 模型适配层；
- 独立 GraphRAG 项目或清晰隔离的子项目；
- GraphRAG 演示与评估报告。

## 验收标准

- [ ] 本地模型失败不会影响主系统默认路径；
- [ ] 对比使用相同输入和评分方法；
- [ ] GraphRAG 可以独立安装和运行；
- [ ] GraphRAG 回答能够展示向量和图关系证据；
- [ ] 两个项目之间的复用边界有文档说明。

## 风险与降级方案

- 本地模型速度或可靠性不足：保留实验报告，不强制接入默认路径；
- 时间不足：优先完成 GraphRisk 可靠性，GraphRAG 缩减为可运行最小版本；
- 显存不足：使用更小量化模型或 CPU 推理。
