# Stage 03：确定性调查工具与无 LLM 工作流

> 状态：Planned  
> 计划时间：Week 4  
> 前置阶段：Stage 02

详细的七条实施路线、每条路线的学习任务与验收方法见 [Stage 03 实施路线](stage-03-implementation-roadmap.md)。路线已于 2026-09-22 编写；本阶段仍为 `Planned`，尚未开始业务代码。

## 阶段目标

在接入 LLM 前，建立可以独立测试的调查工具和确定性调查流程。

## 学习任务

- Tool contract 与结构化输出；
- 幂等性、超时、重试和错误分类；
- 工作流状态与审计日志；
- Agent 工具的安全边界。

## 实现任务

- [ ] `get_transaction`；
- [ ] `get_transaction_features`；
- [ ] `get_risk_score`；
- [ ] `get_related_entities`；
- [ ] `find_risky_neighbors` 的本地占位实现；
- [ ] 明确每个工具的输入、输出和错误模型；
- [ ] 建立不依赖 LLM 的顺序调查流程；
- [ ] 为成功、空结果、无效参数和服务失败编写测试。

## 交付物

- 工具接口与 schema；
- 工具测试；
- 无 LLM 调查报告；
- 审计事件格式。

## 验收标准

- [ ] 所有工具可单独调用；
- [ ] 输出均可由 Pydantic schema 验证；
- [ ] 工具错误不会变成无结构字符串；
- [ ] 无 LLM 工作流能够完成一次基础交易调查；
- [ ] 工具调用过程可追踪。
