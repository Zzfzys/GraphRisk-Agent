# Stage 03：确定性调查工具与无 LLM 工作流

> 状态：Planned  
> 计划时间：Week 4  
> 前置阶段：Stage 02

## 阶段目标

在接入 LLM 前，建立可以独立测试的调查工具和确定性调查流程。

## 学习任务

- Tool contract 与结构化输出；
- 幂等性、超时、重试和错误分类；
- 工作流状态与审计日志；
- Agent 工具的安全边界。

- [ ] `get_transaction`；

- [ ] 建立不依赖 LLM 的顺序调查流程；
- [ ] 为成功、空结果、无效参数和服务失败编写测试。

- 工具测试；

- [ ] 所有工具可单独调用；

- [ ] 无 LLM 工作流能够完成一次基础交易调查；
- [ ] 工具调用过程可追踪。
