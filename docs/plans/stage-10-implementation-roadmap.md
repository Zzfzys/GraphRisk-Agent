## 路线 1：冻结样本、性能口径与实验运行器

**状态：Done（工程）；4h计划额度，含学习1.25h；L1本人Pending。**

目标：先决定如何测量，再观察结果。用交易 ID、时间、覆盖资格选择 10 笔当前增强配置可调查交易，验证/测试各 5 笔，排除旧开发/质量案；不按标签、模型分数或成功与否挑样本。新增样本只是新的系统观察，不是新的欺诈盲测。预先指定 2 笔重复；追加真实请求总上限 14，包含所有阶段/重试/失败及不确定结果。先核对实际调用路径，确保所有模型请求被计数；不能用“12 个 run”替代真实请求数。

建立只追加的 Stage 10 台账，绑定旧 Stage 09 130/144 的文件哈希；旧文件不改，新余额最多 14。预算守卫须在发请求前预留，超时/崩溃未知结果不退款重发。付费 API 和新真实训练均为 0。真实模型计数先用 fake 证明，再启用冻结实验。

复用已有 HTTP、追踪和 psutil/标准库，定义逐请求记录：运行版本、输入 hash、组件/模式、计时起止、模型/提示/schema、状态、错误/超时、尝试数、Token/未知原因、资源与模型驻留证据。无 LLM 的 ready/coverage/读取、真实工具、新事件权重推理、实际 Agent、历史回放分别分组；回放不计推理性能。

API 快速只读组每个冻结分组至少 100 个计时样本才给经验 P99，同时列分位算法和样本数；并发先 1，额外并发最高 2，始终单 worker。真实 Agent 只做上述小样本，不承诺稳定 P99。当前 keep_alive=0 可能不能形成热态；用事实判定，无法证明则记 unknown，不强卸用户模型。

质量门槛预先冻结：10 笔首次结果中来源/受限判断联合通过至少 9，捏造证据/越权动作 0；失败、超时、未运行项都在原分母。该门槛是有限样本可用性门禁，非欺诈识别准确率。人工实用性另评；不得看结果后放宽。合同变更先记版本再实验。

预期产物：实验合同、冻结输入、运行器、预算与统计小型测试、路线 1 报告。验收：伪造时钟/HTTP fixture 验证计时和预算边界、失败分母/低样本/冷暖未知/秘密脱敏；仍不产生真实请求。学习：手算 P50/P95/P99、区分 run/attempt/模型请求和成功率分母。

实际交付：[验收](../../reports/stage-10-route-1-measurement-contract.md)、[命令与75分钟学习](../data/stage-10-measurement.md)，机器合同configs/stage10_measurement.json；CLI freeze/check/dry-run。10首次/2重复、14请求上限和原生发送守卫通过；12次模拟，真实0；CPU898/1平台skip含47新增。计时附录在真实输出前另封存，原样本/门槛不变；下一路线2必须冻结真实执行入口并接资源/台账，不能直接将模拟25ms作性能。

## 路线 2：当前增强 Agent 质量与分层性能实测

**状态：Done（实测工程）；当前真实质量Fail（6/10＜9/10）；L2本人Pending。原估算7h，含学习2h，不冒充实际工时。**

目标：回答当前系统质量和时间消耗分别在哪里。先跑无 LLM 层、记录加载与驻留、检查实际模型 digest 和资源，再按冻结顺序跑 10 笔首次/2 重复；不能偷换为模拟模型。每次真实请求消耗新增台账且总上限 14。只有 2 次失败余量，不因未达门槛额外调用。已完成结果可恢复，从下一个尚未请求的案继续；不把被停止的案移出分母。

CPU 真权重过程沿用已接受的 1.5GiB 系统可用/1280MiB 单进程 RSS 合同，真实 LLM 实验至少 3GiB 可用及服务余量；不得降低原门槛救结果。监控服务/模型进程分别报告，不把一个进程峰值当整机峰值。未知 GPU/Token/冷暖不补 0。用户已有服务、模型和容器不自动结束，改端口需记录。

记录整个 HTTP 往返、工具阶段、生成、加载/重试和错误。报告所有尝试及成功子集的延迟，失败/超时单列；warm/cold 不混合做宣传。小于门槛的分组 P99 留空并解释，P95 也注明小样本。输出瓶颈归因；只做有证据且在本阶段预算内的必要修复，变更后重新冻结受影响验证，不从已观察题选方案。

验收：无 LLM 层可重跑；真实组有原始请求/输出、版本、追加台账与资源证据，原始失败完整；质量 Pass/Fail 与性能“已测/未测”独立结论。若资源或余额挡住，保存部分结果并将真实组记 Pending/Fail，其他交付继续。学习：定位慢在模型、工具还是 UI，解释分位数与冷启动。

实际完成10工具/5真权重/两个100次API组，以及12次真实模型运行。首次6/10，重复2/2，4次安全拒绝、unsafe0；模型HTTP/完整调查P50约9.46/11.36秒。旧130+新增12=142/144。监控修复在模型输出前重新登记；末尾汇总错误仅后处理重算，没有重发或改原答案。见[路线2验收](../../reports/stage-10-route-2-real-measurement.md)和[只读复现说明](../data/stage-10-real-measurement.md)。工程测量完成不代表质量门槛通过。
