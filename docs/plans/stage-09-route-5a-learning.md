# Stage 09 路线 5A 学习路线（2.5 小时）

> 2026-10-08；L5A 待本人完成。配套：[实现路线](stage-09-route-5a-agent-quality.md)。每天30～60分钟，分三至四次完成。

1. **资料与缺失（40分钟）**：选完整和图不覆盖各一案，列金额、1h/24h/7d计数、XGBoost分数、图状态及出处。解释0与不可用；7d交易数为什么不能证明10分钟卡片尝试或独立账户数。
2. **报告职责（40分钟）**：对照旧/新草稿，标出程序绑定长编号、模型判断。故意错选政策、缺图写有图、遗漏未知条件，预测为何拒绝。解释程序生成正确状态为什么不等于模型判断正确。
3. **实验分母（30分钟）**：手算初轮5×3=15，再追加开发5、回归30、重复3、新10，累计63；重复不增加独立交易数。分别列事实/引用、语义、安全、未执行、延迟。解释同时改资料/协议不能单独归因于Prompt。
4. **个人复核（40分钟）**：按固定表读至少10案，含失败/图缺失。核对历史线索、政策条件、分数是否被当概率、人工复核建议依据。用三分钟讲清做了什么、改善多少、仍缺什么。

测试证明机制，实测证明受限任务表现；个人理解和报告实用性由本人复核，不能自动代签。实现后补准确命令、文件与数字。
