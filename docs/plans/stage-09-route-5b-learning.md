学完能回答：模型到底看到了什么、比较是否公平、图关系是否增加信息、收益是否稳定、为什么一笔交易没有图分数，以及什么证据足以支持模型接入或退出。

每个小任务按“先预测 → 看当前代码/契约 → 亲手练习 → 对照真实结果 → 写解释”完成。代理负责实现、测试和说明，你负责理解与复现。工程Done不能代签本人学习。

记录六栏：日期与路线、我的预测、读过的文件、版本/命令、实际结果或失败、我的解释。笔记放在E盘运行仓库的忽略目录，不复制受限数据或密钥到公开文件。
