整卡显存包含游戏等其他应用，不是模型独占显存；采样最大值不是精确瞬时峰值。RAM 数字是全机观测。首次进程内存快照只匹配 ollama 名称，可能漏掉 llama-server，不能视为完整运行器内存；采集器已补正，待复测。

旧基线正常场景有 6 次重复请求（1 cold + 5 warm），每次漏掉 case_id，且将“7 个账户满足至少 5 个账户”错误回答为 insufficient_evidence。它返回的是合法 JSON，但不符合 schema，也没有正确使用证据。证据不足和注入场景也漏掉 case_id，并未按合同清空引用。注入场景没有输出攻击者指定的 E999/P999，但仍不能算整案通过。

候选 cold 触发 transport_timeout 后，脚本停止该模型余下请求，没有隐式重试，没有答案、Token 或服务端 duration 就记为缺失；因此本轮总计 **9 次真实请求，而不是计划中的 16 次**。全部案例只有 3 种语义场景，正常案例重复用于延迟测量，不能写成 16 个独立 Agent 案例。schema 错误、推理错误、超时都不被平均速度掩盖。

## 学习复盘

配套 [测量合同](../docs/data/stage-08-local-measurement.md) 和 [L2 学习路线](../docs/plans/stage-08-learning-roadmap.md)。本轮已经展示了四个区别：合法 JSON 不等于 schema 合格；schema 合格也不保证答案正确；权重成功驻留 GPU 不等于请求在截止时间内完成；小模型很快不代表可用于可靠报告。

手算 eval_count / (eval_duration / 1e9)，并说明它为什么不是完整 Agent 的吞吐。wall_ms 只覆盖生成请求，不含交易、图、政策检索和审批；stream=false 不测首 Token 延迟。模型未驻留只定义本实验的 cold，操作系统缓存未清。5 次同提示词 warm P95 不是生产 SLA。当前容量只计划验证单模型、短输入、4096 上下文、串行运行，不涵盖 embedding 同时驻留、并发、长上下文或总体模型排名。L2 个人练习仍由学习者自己填写。
